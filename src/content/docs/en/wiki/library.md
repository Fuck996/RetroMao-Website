## Main pages

The top navigation has **Library, Recent, Favorites, Apps, Save sync, Plugins** and **Settings**. You can hide Plugins in Appearance settings.

RetroMao returns to the system you last selected when it restarts.

## Default controller buttons

| Button | Action |
| --- | --- |
| D-pad or navigation stick | Move focus within the cover grid |
| A | Select |
| B | Back |
| L1 / R1 | Switch system |
| L2 / R2 | Switch page |
| X | Actions menu |
| Y | Favorite |

Remap buttons in **Settings → Controls**. Your mappings take priority over the defaults. You can also choose **A to select, B to go back** or **B to select, A to go back**, and on-screen hints update to match. Settings warns you about any conflicts.

## Multi-select

Touch and hold a game to start multi-select with that game selected. The actions menu also has a multi-select option.

## Styles and themes

Choose a style in **Settings → Appearance**:

- **Lumen**: A modern style with a background that follows the selected game.
- **Vault**: A system sidebar, game list and details panel. Press left at the far left of the list to enter the sidebar, up or down to switch systems, and right or select to go back.
- **Minimal White and Minimal Black**: Clean, basic styles.

You can also download **Community themes** or import a theme pack. Installing a theme doesn't change your current one, so you can preview it before applying it.

See [Install and update themes](../themes/) for the steps.

## Media preview

Each game can show its cover, 3D box, game media and video. Adjust the options in **Settings → Preview**. Models use a built-in placeholder when artwork is missing.

## Dual-screen handhelds

On dual-screen devices, one screen is for browsing and the other shows models and details. Choose which screen shows the list using the frontend position option in **Settings → Appearance**.

## Language

In **Settings → Appearance → Language**, choose Follow system, Simplified Chinese, Traditional Chinese, English, Japanese or a downloaded language. This only changes the interface, not game names or details.
