## Built-in systems

All 35 systems below include box and game media models.

| Maker | Systems |
| --- | --- |
| Nintendo | Famicom, Famicom Disk System, Super Famicom, Game Boy, Game Boy Color, Game Boy Advance, Nintendo 64, GameCube, Wii, Wii U, Nintendo DS, Nintendo 3DS, Nintendo Switch |
| SEGA | Master System, Mega Drive, Mega CD, 32X, Game Gear, Saturn, Dreamcast |
| Sony | PlayStation, PlayStation 2, PlayStation 3, PSP, PS Vita |
| NEC | PC Engine, PC Engine CD |
| SNK | NEO GEO, NEO GEO CD, NEO GEO Pocket, NEO GEO Pocket Color |
| Bandai | WonderSwan, WonderSwan Color |
| Microsoft | Xbox, Xbox 360 |

Arcade games are also split into CPS, PGM, NAOMI, NEO GEO and other arcade using a built-in ROM database, so one physical folder can cover several systems.

For other systems, install a [community system](../extensions/) or [make your own system pack](../contribute-platform/).

## Supported emulators

| System | Emulators |
| --- | --- |

| PSP | PPSSPP, PPSSPP Gold |
| Nintendo DS | melonDS, DraStic, NooDS |
| Nintendo 3DS | Azahar, Citra variants |
| GameCube, Wii | Dolphin and its variants |
| Nintendo 64 | Mupen64Plus AE, M64Plus FZ |
| PlayStation | DuckStation |
| PlayStation 2 | NetherSX2, ARMSX2 |
| Saturn | Yaba Sanshiro 2 |
| Dreamcast | Flycast |
| PS Vita | Vita3K |
| Wii U | Cemu |
| Nintendo Switch | Eden, Citron, Kenji-NX |

**Settings → Emulators** shows what's available to you. Emulator updates can change how games launch, so include the emulator's name and version when you report a problem.

## Before using an emulator

- **Open the emulator once** to finish its own setup.
- **BIOS and firmware** are read by the emulator, so set them up there.
- **Vita3K**: Games must already be installed in Vita3K.
- **Dolphin multi-disc games**: With an M3U list, RetroMao passes the discs in list order.
