## Requirements

- A phone, tablet or Android handheld running Android 8.0 (API 26) or later
- A recent Android System WebView, if you use script plugins
- The emulators for the games you want to play

## Install

1. On the [Download page](../../download/), download `RetroMao-x.x.x.apk`.
2. You can verify the file using the SHA-256 on the Download page.
3. Open the APK on your device. If prompted, allow the current app to install unknown apps.
4. Open RetroMao, follow the first-run steps and enter your library.

## Update

Install the new APK over the old one. Your library, settings and save links are kept.

:::caution[If you share cloud saves]
Update every device that uses the same cloud saves, including your 3DS, before syncing. Older versions may not be able to read indexes written by newer ones.
:::
