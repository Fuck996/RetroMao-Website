---
title: Install and update themes
description: Install themes from the community or a ZIP file, preview or switch themes, and update installed themes.
---

## Install a theme

- **Download from the community.** Open **Settings → Appearance → Community themes**. Check the author, version and repository, select the themes you want, then tap **Download and install**.
- **Import a ZIP.** Copy the author's theme ZIP to your device without extracting it. Open **Settings → Appearance → Import theme pack** and select the ZIP. Importing works offline.

## Select or preview a theme

After installation, open **Settings → Appearance → Theme**. Installed themes appear above the built-in ones. Select a theme by tapping its name. To try it first, tap the eye icon (**Preview theme**), then use **Apply theme** at the top to save your choice or **Exit preview** to return to your previous appearance.

## Update an installed theme

- **Community themes.** Open **Settings → Appearance → Theme**. When the original repository offers a newer version compatible with your copy of RetroMao, a download icon labeled **Update to v…** appears next to the theme. Tap it, wait for installation to finish, then check the version next to the theme name. **Install community v…** replaces a local theme with its matching official community edition when the local installation has no recorded community version.
- **Local theme packs.** Use **Import theme pack** to select the author's new ZIP for the same theme. When its theme ID matches the installed pack, the new pack replaces it after validation.

Updating in place keeps your current theme selection. If no community update appears, check your connection and whether the original repository is still in your list. If the catalog says the theme requires a newer RetroMao version, update the app first. A failed download or validation leaves the installed pack in place.
