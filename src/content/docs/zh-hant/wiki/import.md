---
title: 匯入已有前端
description: 從 ES-DE、EmulationStation、Pegasus、LaunchBox 匯入資料。
---

如果你已經用過其他前端，可以把資料匯入復古貓。匯入後會轉換為復古貓自己的資料，日常使用和同步不再依賴原來的檔案。

## 支援的格式

| 來源 | 索引檔案 |
| --- | --- |
| ES-DE、EmulationStation | `gamelist.xml` |
| Pegasus | `metadata.txt`、以 `metadata.pegasus` 開頭並以 `.txt` 結尾的檔案 |
| LaunchBox | 機種 XML |

## 自動匯入

新增 ROM 資料夾、重新掃描和下拉重新整理時，復古貓都會檢查資料夾裡的相容索引：

- 只有一份索引時，自動讀取。
- 有多份索引時，先讓你勾選，你的選擇會儲存。候選檔案增減時再重新確認。
- ROM 和媒體的相對路徑按索引檔案所在資料夾解析，不需要重複對映。

## 手動匯入

開啟 **設定 → 遊戲庫與資料夾 → 匯入已有遊戲庫**，選擇索引檔案。如果媒體路徑超出授權範圍（比如來自電腦的磁碟系統代號路徑），可以按提示重新定位。

## 機種如何識別

- Pegasus：讀取已知的 shortname 和集合名
- LaunchBox：讀取 Platform 欄位
- 明確屬於某個機種的 ROM 副檔名和資料夾名

無法判斷時會讓你選擇，不會用當前瀏覽的機種代替。混合了多個機種的索引按機種分別匯入。

:::note[外部啟動命令不會執行]
索引裡的啟動命令不會被執行。遊戲始終由你設定的模擬器啟動。
:::

## 你的修改會保留

重新匯入時，收藏、遊玩記錄和你修改過的資料都會保留。
