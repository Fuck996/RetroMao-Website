title: 安裝與更新主題
description: 安裝社群主題或本機主題包，預覽、切換和更新已安裝的主題。
---

## 安裝主題

- **從社群下載**。開啟 **設定 → 主題與顯示 → 社群主題**，確認主題的作者、版本和倉庫，勾選要安裝的主題，再點選 **下載並安裝**。
- **匯入 ZIP**。將作者提供的主題 ZIP 原樣複製到裝置，開啟 **設定 → 主題與顯示 → 匯入主題包**，選擇 ZIP 檔案。匯入可離線完成。

## 選擇或預覽主題

安裝完成後，開啟 **設定 → 主題與顯示 → 主題**。已安裝的主題排在內建主題前面。點選主題名稱即可切換，也可以點選該列的眼睛圖示進入 **預覽主題**，再用頂端的 **套用主題** 儲存，或點選 **退出預覽** 回到原本的外觀。

## 更新已安裝的主題

- **社群主題**。開啟 **設定 → 主題與顯示 → 主題**。有來自原倉庫且與目前復古貓版本相容的更新時，主題右側會顯示 **更新至某版本** 的下載圖示。點選圖示，等候下載及安裝完成，再核對主題旁的版本號。若顯示 **安裝社群版**，這是將未記錄社群版本的本機主題換成對應的官方社群版。
- **本機主題包**。透過 **匯入主題包** 選擇作者提供的同一個主題的新版 ZIP。包內主題 ID 相同時，新版通過驗證後會取代已安裝的舊版。

直接更新即可保留目前選用的主題。若未顯示社群更新，請檢查網路及原倉庫是否仍在倉庫清單中。若社群目錄提示需要更新版本的復古貓，請先更新應用程式。下載或驗證失敗時，會保留已安裝的主題包。
