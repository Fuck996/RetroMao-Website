復古貓的功能不止內建的這些。外掛程式可以增加新功能和新頁面，而且不需要修改主程式或重新打包 APK。

## 外掛程式是什麼

一個外掛程式是一個 ZIP，包含清單 `plugin.json`、背景指令碼和可選的網頁。指令碼透過公開的 SDK 呼叫復古貓的能力。

| 組成 | 作用 |
| --- | --- |
| 清單 | 宣告名稱、作者、版本、最低應用版本、需要的能力和頁面 |
| 背景動作 | 在隔離的 JavaScript 引擎中執行，可以長時間處理、報告進度 |
| 頁面 | 用 HTML、CSS 和 JavaScript 編寫，在復古貓的導航內開啟 |
| 設定 | 由宿主繪製表單，也可以自己寫設定頁。金鑰欄位會加密儲存 |

## 外掛程式能做什麼

- 讀取和修改遊戲資料、收藏和最近記錄
- 查詢和關聯已授權的媒體
- 儲存擴充欄位，並隨索引同步到其他裝置
- 訪問宣告過的網路主機
- 在你允許的網盤連線中讀寫 JSON 文件
- 為系統 ROM 同步增加額外的遊戲資源
- 增加模擬器啟動入口和搜尋匹配方式

## 現在可以安裝的外掛程式

在 **外掛程式 → 商店** 中可以安裝：

| 外掛程式 | 作用 |
| --- | --- |
| 收藏同步 | 透過已設定的網盤同步收藏，不傳輸 ROM、媒體或存檔 |
| 最近遊戲記錄同步 | 同步最近遊玩時間、次數和時長 |
| 拼音首字母搜尋 | 用拼音首字母搜尋遊戲和應用，例如 `jsq` 搜尋計算器 |
| Vita3K ROM 同步 | 同步 Vita3K 的遊戲本體、補丁、DLC 和許可 |
| 自定義啟動入口 | 選擇機種並自定義模擬器啟動引數 |

## 你如何控制權限

外掛程式必須宣告它需要的能力，你同意後才能啟用：

| 能力 | 含義 |
| --- | --- |
| `LIBRARY_READ` | 讀取遊戲庫 |
| `LIBRARY_WRITE` | 修改資料、收藏、最近記錄和媒體關聯 |
| `NETWORK` | 訪問宣告過的主機 |
| `STORAGE` | 讀寫你允許的網盤連線中的 JSON 文件 |

- 更新時如果新增了能力或主機，外掛程式會保持停用，直到你重新同意。
- 可以訪問任意主機的外掛程式會被標為高風險。
- 外掛程式讀不到其他外掛程式的擴充欄位，也拿不到其他來源的設定和金鑰。
- 可以隨時在外掛程式詳情中停用或解除安裝，解除安裝時可以選擇清除資料。

:::caution
外掛程式可以執行程式碼，請只安裝你信任的來源。
:::

## 不影響遊戲

啟動遊戲不等待外掛程式。背景指令碼按需建立，任務結束後釋放；關閉頁面不會取消任務。中斷後不會自動重放，可以手動重新執行。
