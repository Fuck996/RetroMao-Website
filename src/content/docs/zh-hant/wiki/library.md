## 主要頁面

頂部導航依次是 **遊戲庫、最近遊戲、收藏、應用、存檔同步、外掛程式** 和 **設定**。外掛程式入口可以在「主題與顯示」中隱藏。

再次啟動時，復古貓會回到上次選擇的機種。

## 預設控制器操作

| 按鍵 | 作用 |
| --- | --- |
| 方向鍵／導航搖桿 | 在封面網格內移動焦點 |
| A | 確認 |
| B | 返回 |
| L1 / R1 | 切換機種 |
| L2 / R2 | 切換頁面 |
| X | 操作選單 |
| Y | 收藏 |

按鍵可以在 **設定 → 控制器與按鍵** 中重新對映，你的對映優先於預設設定。這裡還可以選擇 **A 確認／B 返回** 或 **B 確認／A 返回**，提示文字會同步變化。存在衝突時，設定頁會明確提示。

## 多選

長按遊戲會進入多選並選中當前遊戲。操作選單也提供多選入口。

## 介面風格與主題

在 **設定 → 主題與顯示** 中選擇：

- **流光**：背景隨選中遊戲變化的現代風格。
- **藏館**：左側機種欄、遊戲列表和右側詳情。在列表最左側按左鍵進入機種欄，上下切換機種，按右鍵或確認返回。
- **簡約白／簡約黑**：乾淨的基礎風格。

還可以從 **社群主題** 下載主題，或匯入主題包。安裝不會立刻改變當前主題，可以先預覽再應用。

## 媒體預覽

每款遊戲可以顯示封面、3D 包裝盒、遊戲介質和影片。**設定 → 媒體預覽** 可以調整相關選項。缺少貼圖時，模型使用內建佔點陣圖。

## 雙屏掌機

在雙屏裝置上，一塊螢幕瀏覽和選擇遊戲，另一塊螢幕顯示模型和資料。在 **設定 → 主題與顯示 → 前端顯示位置** 中可以選擇瀏覽列表在上屏還是下屏。

## 語言

**設定 → 主題與顯示 → 語言**：可以選擇跟隨系統、簡中、繁中、英語、日語或已下載的語言。語言隻影響介面文字，不改變遊戲名稱和資料。
