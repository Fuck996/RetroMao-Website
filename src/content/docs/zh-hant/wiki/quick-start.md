## 1. 整理 ROM 資料夾

推薦把遊戲按機種放在一個總資料夾下：

```text
ROMs/
├── FC/
├── SFC/
├── GBA/
└── PSX/
```

## 2. 新增 ROM 總資料夾

1. 開啟 **設定 → 遊戲庫與資料夾 → 新增 ROM 資料夾**。
2. 在系統檔案選擇器中選擇總資料夾（如 `ROMs`），並授權訪問。
3. 復古貓根據資料夾名、索引和明確的副檔名發現機種。只有無法識別的資料夾才會詢問你。

不需要逐個新增機種。街機資料夾會按內建識別庫自動劃分系列。

## 3. 新增媒體（可選）

下面這些內容會在掃描時自動匹配：

- 與 ROM 同名的 PNG、JPG、WebP、BMP、GIF 圖片，以及 MP4、WebM、AVI 影片
- ROM 資料夾及其子資料夾中的媒體
- `-cover`、`_box_front`、`-cartridge`、`-disc`、`-logo` 等常見命名
- 資料夾裡已有的 `gamelist.xml`、`metadata.pegasus.txt` 等索引

媒體放在其他位置時，使用 **新增媒體資料夾**，再重新掃描對應的 ROM 資料夾。

缺少封面時，遊戲庫顯示內建的佔點陣圖，3D 模型仍然可以預覽。

## 4. 設定模擬器

1. 安裝模擬器，先開啟一次完成初始化。
2. 開啟 **設定 → 模擬器與啟動**，為機種選擇模擬器。使用 RetroArch 時還需要選擇核心。

## 5. 開始遊戲

回到遊戲庫，選中遊戲後按 A 或點選 **開始遊戲**。

## 遊戲庫如何保持更新

啟動、回到前端和下拉重新整理時，復古貓會在背景檢查：

- 自動發現新增的 ROM 和索引變化。
- ROM 檔案被刪除後，如果網盤中也沒有，就從列表隱藏。資料、收藏和存檔關聯會保留，檔案恢復後沿用原記錄。
- TF 卡拔出或暫時讀取不到時，不會判定為刪除，重新插入後自動恢復。
