## 內建機種

下列 35 個機種都有包裝盒和遊戲介質模型。

| 廠商 | 機種 |
| --- | --- |
| 任天堂 | FC、FC 磁碟系統、SFC、Game Boy、Game Boy Color、Game Boy Advance、N64、GameCube、Wii、Wii U、NDS、3DS、Switch |
| 世嘉 | Master System、Mega Drive、Mega CD、32X、Game Gear、Saturn、Dreamcast |
| 索尼 | PlayStation、PlayStation 2、PlayStation 3、PSP、PS Vita |
| NEC | PC Engine、PC Engine CD |
| SNK | NEO GEO、NEO GEO CD、NEO GEO Pocket、NEO GEO Pocket Color |
| 萬代 | WonderSwan、WonderSwan Color |
| 微軟 | Xbox、Xbox 360 |

街機另外按內建 ROM 識別庫劃分為 CPS、PGM、NAOMI、NEO GEO 和其他街機，同一個物理資料夾可以分屬多個機種。

需要其他機種時，可以安裝 [社群機種](../extensions/)，或者 [自己製作機種包](../contribute-platform/)。

## 已適配的模擬器

復古貓透過各模擬器公開的啟動入口傳遞 ROM。模擬器需要你自行安裝並完成首次初始化。

| 機種 | 模擬器 |
| --- | --- |
| 多機種 | RetroArch、RetroArch 64 |
| PSP | PPSSPP、PPSSPP Gold |
| NDS | melonDS、DraStic、NooDS |
| 3DS | Azahar、Citra 派生版 |
| GameCube、Wii | Dolphin 及其派生版 |
| N64 | Mupen64Plus AE、M64Plus FZ |
| PlayStation | DuckStation |
| PlayStation 2 | NetherSX2、ARMSX2 |
| Saturn | Yaba Sanshiro 2 |
| Dreamcast | Flycast |
| PS Vita | Vita3K |
| Wii U | Cemu |
| Switch | Eden、Citron、Kenji-NX |

可選的模擬器以 **設定 → 模擬器與啟動** 中的列表為準。第三方模擬器更新可能改變啟動方式；遇到問題時，請反饋模擬器的名稱和版本。

## 使用模擬器前

- **先開啟一次模擬器**，完成它自己的初始化。
- **BIOS 和韌體**由模擬器讀取，請在模擬器內設定。
- **Vita3K**：遊戲須已安裝在 Vita3K 內。
- **Dolphin 多碟遊戲**：使用 M3U 列表時，復古貓按列表順序傳遞光碟。
