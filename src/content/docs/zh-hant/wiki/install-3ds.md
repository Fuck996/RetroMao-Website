---
title: 安裝 3DS 同步程式
description: 在 3DS 上安裝同步程式，並透過區域網匯入網盤設定。
---

3DS 同步程式透過系統存檔服務直接讀寫遊戲實際使用的存檔，不依賴 Checkpoint。它支援 WebDAV 和百度網盤，並與 Android 版共用同一份網盤存檔。

## 準備

- 已安裝 Luma3DS 等自制韌體，並可以執行 FBI。未改機的原廠系統不能安裝 CIA，可以參考 [3DS Hacks Guide](https://3ds.hacks.guide/finalizing-setup.html)。
- 一臺已經設定好網盤的 Android 版復古貓，並與 3DS 處於同一區域網。

## 安裝

1. 從 [下載頁](../../download/) 下載 `RetroMao-3DS-x.x.x.cia`。
2. 把 CIA 複製到 SD 卡的 `cias` 資料夾。
3. 開啟 FBI，進入 `SD → cias`，選中 CIA，選擇 `Install and delete CIA`，按 A 確認。
4. 返回 HOME 選單，開啟 RetroMao。

升級時用 FBI 安裝新版覆蓋即可。`sdmc:/3ds/RetroMao/` 中的設定、任務記錄和備份會保留。

## 匯入網盤設定

3DS 上不能手動填寫帳號，設定只透過區域網一鍵設定匯入。

1. 在 3DS 上開啟 `START → 同步設定 → 一鍵設定 → 我是新裝置`，螢幕會顯示本機 IP 和四位配對碼。
2. 在 Android 版開啟 **設定 → 網盤與 WebDAV → 一鍵設定 → 我是老裝置**，發現或手動輸入 3DS 的 IP，再輸入配對碼。
3. 勾選要傳輸的連線，點選「同步設定」。
4. 回到 3DS 的同步設定，選用一個同步來源。

## 存檔同步

1. 在下屏網格中選擇遊戲：觸控或按 A 勾選，方向鍵移動焦點，L/R 翻頁。
2. 按 START，選擇 **存檔同步**，確認所選的遊戲和來源。
3. 等待完成。上屏會顯示實際階段和逐項結果。

:::note[中斷了也不用擔心]
下載的存檔會先完整暫存並校驗，再備份當前存檔，最後寫入。中斷後需要先恢復或完成原任務，才能繼續同步。
:::

下屏左上角的 `Language`（SELECT）可以切換簡中、繁中、英語和日語。

## 限制

- 部分遊戲的擴充存檔需要確認歸屬後才能同步，程式會列出遊戲和檔案 ID，由你確認或跳過。
- 部分系統（如 Luma3DS 7.1）限制 Loader 連線，可能無法確認擴充存檔，結果中會註明。
- 存檔存在不可讀區域時，結果會顯示「已同步可讀區域」和原始錯誤碼。這個過程不會修復損壞的資料。
- 憑據繫結當前主機，複製 `sdmc:/3ds/RetroMao/` 到另一臺主機不能代替一鍵設定。
