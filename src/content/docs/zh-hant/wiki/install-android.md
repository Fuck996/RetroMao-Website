## 系統要求

- Android 8.0（API 26）及以上的手機、平板或安卓掌機
- 使用指令碼外掛程式時，需要較新的 Android System WebView
- 啟動遊戲需要另外安裝對應的模擬器

## 安裝

1. 開啟 [下載頁](../../download/)，下載 `RetroMao-x.x.x.apk`。
2. 可以用下載頁提供的 SHA-256 核對檔案。
3. 在裝置上開啟 APK。系統詢問時，允許當前應用安裝未知來源的應用。
4. 開啟復古貓，按首次引導操作，然後進入遊戲庫。

## 升級

直接安裝新版 APK 覆蓋舊版即可，遊戲庫、設定和存檔關聯都會保留。

:::caution[共用網盤存檔時]
使用同一份網盤存檔的所有裝置（包括 3DS）都應升級到最新版後再同步。舊版可能無法讀取新版寫入的索引。
:::
