---
title: 安裝擴充
description: 新增擴充倉庫，安裝語言、機種、主題和外掛程式。
---

擴充來自公開的 GitHub 倉庫。官方倉庫是 [RetroMao-Community](https://github.com/Fuck996/RetroMao-Community)，也可以新增其他人維護的 Fork。

## 新增倉庫

1. 點選 **設定首頁右下角** 沒有文字的倉庫按鈕。
2. 每行填寫一個公開 GitHub 倉庫地址。
3. 儲存。語言、主題、機種和外掛程式共用這份列表。

要同時使用官方和社群內容，請保留各自的一行。清空列表後，不會請求任何倉庫。

## 線上安裝

| 型別 | 入口 |
| --- | --- |
| 語言 | 設定 → 主題與顯示 → 語言 → 下載語言 |
| 主題 | 設定 → 主題與顯示 → 社群主題 |
| 機種 | 設定 → 遊戲庫與資料夾 → 社群機種 |
| 外掛程式 | 主導覽 → 外掛程式 → 商店 |

下載時會核對精確大小和 SHA-256，不一致的檔案不會進入安裝流程。線上下載需要能訪問 GitHub。

## 離線安裝

從倉庫的 Release 下載 ZIP，**不要解壓**，複製到裝置後匯入：

- 主題：**設定 → 主題與顯示 → 匯入主題包**
- 機種：**設定 → 遊戲庫與資料夾 → 匯入機種擴充包**
- 外掛程式：**外掛程式 → 已安裝** 中匯入

## 安全

- 語言、機種和主題只包含設定與素材，不執行程式碼。
- 外掛程式可以執行指令碼，但只能使用它宣告且你同意的能力。更新時如果新增了能力，外掛程式會保持停用，直到你重新同意。
- 宣告可訪問任意主機的外掛程式會被標為高風險，請只安裝你信任的外掛程式。

## 機種包不包含什麼

機種包定義機種身份、副檔名和圖示等，**不附帶遊戲和模擬器**。安裝後仍需要新增 ROM 資料夾並設定模擬器。
