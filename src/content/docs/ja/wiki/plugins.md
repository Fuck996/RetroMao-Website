RetroMao の機能は内蔵のものだけではありません。プラグインを使えば、本体の変更や APK の再ビルドなしで機能とページを追加できます。

## プラグインとは

プラグインは、マニフェスト `plugin.json`、バックグラウンドスクリプト、任意の Web ページを含む ZIP です。スクリプトは公開 SDK を通じて RetroMao の機能を呼び出します。

| 構成要素 | 役割 |
| --- | --- |
| マニフェスト | 名前、作者、バージョン、必要なアプリのバージョン、機能、ページを宣言します |
| バックグラウンド処理 | 分離された JavaScript エンジンで動作し、長い処理と進行状況の報告ができます |
| ページ | HTML、CSS、JavaScript で作成し、RetroMao のナビゲーション内で開きます |
| 設定 | ホストがフォームを描画します。独自の設定ページも作成でき、秘密の項目は暗号化して保存します |

## プラグインでできること

- ゲーム情報、お気に入り、最近の記録の読み取りと変更
- 許可されたメディアの検索と関連付け
- インデックスとともに他の端末へ同期する拡張フィールドの保存
- 宣言したネットワークホストへのアクセス
- 許可したクラウド接続での JSON ドキュメントの読み書き
- システムの ROM 同期へのゲームリソースの追加
- エミュレーターの起動設定と検索方法の追加

## 今すぐインストールできるプラグイン

**プラグイン → ストア** からインストールできます。

| プラグイン | 内容 |
| --- | --- |
| お気に入りの同期 | 設定済みのクラウド接続でお気に入りを同期します。ROM、メディア、セーブは転送しません |
| 最近遊んだゲームの同期 | 最終プレイ日、回数、時間を同期します |
| ピンイン頭文字検索 | ゲームとアプリを中国語ピンインの頭文字で検索します（例：`jsq` で「计算器」） |
| Vita3K ROM 同期 | Vita3K のゲーム本体、更新、DLC、ライセンスを同期します |
| カスタム起動設定 | 機種を選び、エミュレーターの起動パラメーターを設定します |

## 権限の管理

プラグインは必要な機能を宣言し、あなたが許可してから有効になります。

| 機能 | 意味 |
| --- | --- |
| `LIBRARY_READ` | ライブラリの読み取り |
| `LIBRARY_WRITE` | 情報、お気に入り、最近の記録、メディアの関連付けの変更 |
| `NETWORK` | 宣言したホストへのアクセス |
| `STORAGE` | 許可したクラウド接続の JSON ドキュメントの読み書き |

- 更新で機能やホストが増えると、再度許可するまで無効のままです。
- 任意のホストにアクセスできるプラグインは高リスクと表示されます。
- 他のプラグインの拡張フィールドや、他の配布元の設定と秘密情報は読み取れません。
- 詳細画面からいつでも無効化やアンインストールができ、アンインストール時にデータの消去も選べます。

:::caution
プラグインはコードを実行できます。信頼できる配布元のものだけをインストールしてください。
:::

## ゲームへの影響

ゲームの起動はプラグインを待ちません。バックグラウンドスクリプトは必要なときに作成され、終了後に解放されます。ページを閉じてもタスクはキャンセルされません。中断したタスクは自動で再実行されませんが、手動で実行し直せます。
