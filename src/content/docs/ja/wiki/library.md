## おもなページ

上部のナビゲーションには **ライブラリ、最近、お気に入り、アプリ、セーブ同期、プラグイン、設定** が並びます。プラグインは「外観」の設定で非表示にできます。

再起動すると、最後に選んだ機種に戻ります。

## 既定のコントローラー操作

| ボタン | 操作 |
| --- | --- |
| 十字キー／ナビゲーションスティック | カバーのグリッド内でフォーカスを移動 |
| A | 決定 |
| B | 戻る |
| L1 / R1 | 機種を切り替え |
| L2 / R2 | ページを切り替え |
| X | 操作メニュー |
| Y | お気に入り |

**設定 → 操作設定** でボタンを割り当て直せます。ユーザーの割り当ては既定より優先されます。**A で決定、B で戻る** と **B で決定、A で戻る** も選べて、画面の案内も連動します。競合があると設定画面でお知らせします。

## 複数選択

ゲームを長押しすると、そのゲームを選択した状態で複数選択に入ります。操作メニューからも複数選択できます。

## スタイルとテーマ

**設定 → 外観** で選択します。

- **ルーメン**：背景が選択中のゲームに合わせて変わるモダンなスタイルです。
- **ヴォルト**：機種サイドバー、ゲーム一覧、詳細パネルの構成です。一覧の左端で左を押すとサイドバーに入り、上下で機種を切り替え、右または決定で戻ります。
- **シンプル白／シンプル黒**：すっきりした基本のスタイルです。

**コミュニティのテーマ** をダウンロードしたり、テーマパックをインポートしたりできます。インストールしても現在のテーマは変わらないので、プレビューしてから適用できます。

## メディアプレビュー

ゲームごとにカバー、3D パッケージ、ゲームメディア、動画を表示できます。**設定 → プレビュー** でオプションを調整できます。画像がないときは内蔵のプレースホルダーをモデルに使います。

## 2 画面の携帯機

2 画面の端末では、片方の画面でゲームを選び、もう片方にモデルと情報を表示します。**設定 → 外観** のフロントエンドの表示位置で、一覧を表示する画面を選べます。

## 言語

**設定 → 外観 → 言語** で、システムに従う、簡体字中国語、繁体字中国語、英語、日本語、ダウンロードした言語を選べます。変わるのは画面の文字だけで、ゲーム名や情報は変わりません。
