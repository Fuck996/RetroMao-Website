## 1. ROM を整理する

ルートフォルダーの下に、機種ごとのフォルダーを置くことをおすすめします。

```text
ROMs/
├── FC/
├── SFC/
├── GBA/
└── PSX/
```

## 2. ROM のルートフォルダーを追加する

1. **設定 → ライブラリ → ROM フォルダーを追加** を開きます。
2. システムのファイル選択画面でルートフォルダー（例：`ROMs`）を選び、アクセスを許可します。
3. RetroMao はフォルダー名、インデックス、明確な拡張子から機種を判別します。判別できないフォルダーだけ確認します。

機種を 1 つずつ追加する必要はありません。アーケードのフォルダーは内蔵データベースでシリーズごとに自動で分類します。

## 3. メディアを追加する（任意）

スキャン時に次のものを自動で関連付けます。

- ROM と同じ名前の PNG、JPG、WebP、BMP、GIF 画像と MP4、WebM、AVI 動画
- ROM フォルダーとそのサブフォルダーにあるメディア
- `-cover`、`_box_front`、`-cartridge`、`-disc`、`-logo` などの一般的な名前
- フォルダー内の `gamelist.xml`、`metadata.pegasus.txt` などのインデックス

メディアが別の場所にある場合は、**メディアフォルダーを追加** してから、対応する ROM フォルダーを再スキャンしてください。

カバーがないときはライブラリに内蔵のプレースホルダーが表示され、3D モデルもプレビューできます。

## 4. エミュレーターを設定する

1. エミュレーターをインストールし、一度起動して初期設定を済ませます。
2. **設定 → エミュレーター** を開き、機種ごとにエミュレーターを選びます。RetroArch ではコアも選びます。

## 5. プレイする

ライブラリに戻り、ゲームを選んで A を押すか **プレイ** をタップします。

## ライブラリの更新

RetroMao は起動時、フロントエンドに戻ったとき、下に引いて更新したときに、バックグラウンドで次の確認を行います。

- 新しい ROM とインデックスの変更を自動で見つけます。
- ROM を削除し、クラウドにもない場合は一覧から非表示にします。情報、お気に入り、セーブの関連付けは保持され、ファイルが戻ると同じ記録を使います。
- SD カードを抜いたときや一時的に読み取れないときは、削除とみなしません。挿し直すと自動で復帰します。
