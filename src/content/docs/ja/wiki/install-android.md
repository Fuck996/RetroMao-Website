## 動作条件

- Android 8.0（API 26）以降のスマートフォン、タブレット、Android 携帯機
- スクリプトプラグインを使う場合は、新しい Android System WebView
- 遊ぶゲームに対応するエミュレーター

## インストール

1. [ダウンロードページ](../../download/) から `RetroMao-x.x.x.apk` をダウンロードします。
2. ダウンロードページの SHA-256 でファイルを確認できます。
3. 端末で APK を開きます。確認画面が表示されたら、そのアプリからのインストールを許可します。
4. RetroMao を開き、最初の案内に従ってライブラリに入ります。

## 更新

新しい APK を上書きインストールしてください。ライブラリ、設定、セーブの関連付けは保持されます。

:::caution[クラウドセーブを共有している場合]
同じクラウドセーブを使うすべての端末（3DS を含む）を最新版に更新してから同期してください。古いバージョンでは、新しいバージョンが書き込んだインデックスを読み取れない場合があります。
:::
