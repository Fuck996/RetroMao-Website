---
title: 3DS 同期アプリをインストール
description: 3DS に同期アプリをインストールし、ローカルネットワークでクラウド設定を取り込みます。
---

3DS 同期アプリは、システムのセーブサービスを通じてゲームが実際に使うセーブを直接読み書きします。Checkpoint は不要です。WebDAV と Baidu Netdisk に対応し、Android 版と同じクラウドセーブを使います。

## 準備

- Luma3DS などのカスタムファームウェアと FBI が必要です。改造していないシステムには CIA をインストールできません。[3DS Hacks Guide](https://3ds.hacks.guide/finalizing-setup.html) をご覧ください。
- クラウドを設定済みの RetroMao Android 版が、3DS と同じローカルネットワークにある必要があります。

## インストール

1. [ダウンロードページ](../../download/) から `RetroMao-3DS-x.x.x.cia` をダウンロードします。
2. CIA を SD カードの `cias` フォルダーにコピーします。
3. FBI を開いて `SD → cias` に進み、CIA を選んで `Install and delete CIA` を選択し、A で確定します。
4. HOME メニューに戻り、RetroMao を開きます。

更新するときは、FBI で新しいバージョンを上書きインストールします。`sdmc:/3ds/RetroMao/` の設定、タスク記録、バックアップは保持されます。

## クラウド設定を取り込む

3DS ではアカウント情報を入力できません。設定はローカルネットワークのワンタッチ設定でのみ取り込みます。

1. 3DS で `START → 同期設定 → ワンタッチ設定 → 新しい端末` を開きます。画面に IP アドレスと 4 桁のペアリングコードが表示されます。
2. Android 版で **設定 → クラウドと WebDAV → ワンタッチ設定（一键配置）→ 既存の端末（我是老设备）** を開きます。3DS を見つけるか IP アドレスを入力し、ペアリングコードを入力します。
3. 送信する接続を選び、**設定を同期（同步配置）** をタップします。
4. 3DS の同期設定に戻り、同期元を選択します。

表示されるラベルは言語によって多少異なる場合があります。

## セーブを同期

1. 下画面のグリッドでゲームを選びます。タッチまたは A で選択、十字キーで移動、L/R でページを切り替えます。
2. START を押して **セーブを同期** を選び、ゲームと同期元を確認します。
3. 完了を待ちます。上画面に各段階と結果が表示されます。

:::note[中断した場合]
ダウンロードしたセーブは、まず全体を一時保存して検証し、現在のセーブをバックアップしてから書き込みます。中断後は、元のタスクを復元または完了してから同期してください。
:::

下画面左上の `Language`（SELECT）で、簡体字中国語、繁体字中国語、英語、日本語を切り替えられます。

## 制限事項

- 一部のゲームの追加データは、関連付けの確認が必要です。ゲームとアーカイブ ID が表示されるので、確認するかスキップしてください。
- Luma3DS 7.1 など一部のシステムでは Loader 接続が制限され、追加データを確認できないことがあります。その場合は結果に表示されます。
- セーブに読み取れない領域があると、読み取れた領域のみ同期したことと元のエラーコードが表示されます。破損したデータは修復されません。
- 認証情報は現在の本体に結び付けられます。`sdmc:/3ds/RetroMao/` を別の本体にコピーしても、ワンタッチ設定の代わりにはなりません。
