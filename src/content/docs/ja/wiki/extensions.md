---
title: 拡張をインストール
description: 拡張リポジトリを追加し、言語、機種、テーマ、プラグインをインストールします。
---

拡張は公開 GitHub リポジトリから提供されます。公式は [RetroMao-Community](https://github.com/Fuck996/RetroMao-Community) で、他の人が管理する Fork も追加できます。

## リポジトリを追加

1. **設定ホームの右下** にある文字のないリポジトリボタンをタップします。
2. 公開 GitHub リポジトリの URL を 1 行に 1 つ入力します。
3. 保存します。言語、テーマ、機種、プラグインはこの一覧を共有します。

公式とコミュニティの両方を使うには、それぞれの行を残してください。一覧が空のときは、どのリポジトリにもアクセスしません。

## オンラインでインストール

| 種類 | 場所 |
| --- | --- |
| 言語 | 設定 → 外観 → 言語 → 言語をダウンロード |
| テーマ | 設定 → 外観 → コミュニティのテーマ |
| 機種 | 設定 → ライブラリ → コミュニティの機種 |
| プラグイン | メインナビゲーション → プラグイン → ストア |

ダウンロード時に正確なサイズと SHA-256 を確認し、一致しないファイルはインストールしません。オンラインのダウンロードには GitHub へのアクセスが必要です。

## オフラインでインストール

リポジトリの Release から ZIP をダウンロードし、**展開せずに** 端末にコピーしてインポートします。

- テーマ：**設定 → 外観 → テーマパックをインポート**
- 機種：**設定 → ライブラリ → 機種拡張パックをインポート**
- プラグイン：**プラグイン → インストール済み** からインポート

インストール、プレビュー、更新の手順は [テーマのインストールと更新](../themes/) をご覧ください。

## セキュリティ

- 言語、機種、テーマは設定と素材のみを含み、コードを実行しません。
- プラグインはスクリプトを実行できますが、宣言され、あなたが許可した機能だけを使えます。更新で機能が増えると、再度許可するまで無効のままです。
- 任意のホストにアクセスできるプラグインは高リスクと表示されます。信頼できるプラグインだけをインストールしてください。

## 機種パックに含まれないもの

機種パックは機種の情報、拡張子、アイコンなどを定義します。**ゲームとエミュレーターは含まれません。** インストール後に ROM フォルダーの追加とエミュレーターの設定が必要です。
