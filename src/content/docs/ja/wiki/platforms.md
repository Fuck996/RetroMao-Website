## 内蔵の機種

次の 35 機種すべてに、パッケージとゲームメディアのモデルがあります。

| メーカー | 機種 |
| --- | --- |
| 任天堂 | ファミコン、ディスクシステム、スーパーファミコン、ゲームボーイ、ゲームボーイカラー、ゲームボーイアドバンス、NINTENDO 64、ゲームキューブ、Wii、Wii U、ニンテンドー DS、ニンテンドー 3DS、Nintendo Switch |
| セガ | セガ・マークIII / マスターシステム、メガドライブ、メガ CD、スーパー 32X、ゲームギア、セガサターン、ドリームキャスト |
| ソニー | PlayStation、PlayStation 2、PlayStation 3、PSP、PS Vita |
| NEC | PC エンジン、PC エンジン CD |
| SNK | NEOGEO、NEOGEO CD、NEOGEO POCKET、NEOGEO POCKET COLOR |
| バンダイ | ワンダースワン、ワンダースワンカラー |
| マイクロソフト | Xbox、Xbox 360 |

アーケードは内蔵の ROM データベースで CPS、PGM、NAOMI、NEO GEO、その他のアーケードに分類します。1 つのフォルダーを複数の機種に割り当てられます。

ほかの機種は、[コミュニティの機種](../extensions/) をインストールするか、[機種パックを自作](../contribute-platform/) できます。

## 対応エミュレーター

RetroMao は各エミュレーターの公開された入口から ROM を渡します。エミュレーターはご自身でインストールし、初期設定を済ませてください。

| 機種 | エミュレーター |
| --- | --- |
| 複数機種 | RetroArch、RetroArch 64 |
| PSP | PPSSPP、PPSSPP Gold |
| ニンテンドー DS | melonDS、DraStic、NooDS |
| ニンテンドー 3DS | Azahar、Citra 派生版 |
| ゲームキューブ、Wii | Dolphin とその派生版 |
| NINTENDO 64 | Mupen64Plus AE、M64Plus FZ |
| PlayStation | DuckStation |
| PlayStation 2 | NetherSX2、ARMSX2 |
| セガサターン | Yaba Sanshiro 2 |
| ドリームキャスト | Flycast |
| PS Vita | Vita3K |
| Wii U | Cemu |
| Nintendo Switch | Eden、Citron、Kenji-NX |

選択できるエミュレーターは **設定 → エミュレーター** の一覧で確認できます。エミュレーターの更新で起動方法が変わることがあるため、問題を報告するときは名前とバージョンをお知らせください。

## エミュレーターを使う前に

- **エミュレーターを一度起動**して、初期設定を済ませてください。
- **BIOS とファームウェア**はエミュレーターが読み込むため、エミュレーター側で設定してください。
- **Vita3K**：ゲームを Vita3K にインストールしておく必要があります。
- **Dolphin の複数ディスク**：M3U リストを使うと、リストの順にディスクを渡します。
