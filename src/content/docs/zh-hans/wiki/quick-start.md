## 1. 整理 ROM 目录

推荐把游戏按机种放在一个总目录下：

```text
ROMs/
├── FC/
├── SFC/
├── GBA/
└── PSX/
```

## 2. 添加 ROM 总目录

1. 打开 **设置 → 游戏库与文件夹 → 添加 ROM 目录**。
2. 在系统文件选择器中选择总目录（如 `ROMs`），并授权访问。
3. 复古猫根据目录名、索引和明确的扩展名发现机种。只有无法识别的目录才会询问你。

不需要逐个添加机种。街机目录会按内置识别库自动划分系列。

## 3. 添加媒体（可选）

下面这些内容会在扫描时自动匹配：

- 与 ROM 同名的 PNG、JPG、WebP、BMP、GIF 图片，以及 MP4、WebM、AVI 视频
- ROM 目录及其子目录中的媒体
- `-cover`、`_box_front`、`-cartridge`、`-disc`、`-logo` 等常见命名
- 目录里已有的 `gamelist.xml`、`metadata.pegasus.txt` 等索引

媒体放在其他位置时，使用 **添加媒体目录**，再重新扫描对应的 ROM 目录。

缺少封面时，游戏库显示内置的占位图，3D 模型仍然可以预览。

## 4. 配置模拟器

1. 安装模拟器，先打开一次完成初始化。
2. 打开 **设置 → 模拟器与启动**，为机种选择模拟器。使用 RetroArch 时还需要选择核心。

## 5. 开始游戏

回到游戏库，选中游戏后按 A 或点击 **开始游戏**。

## 游戏库如何保持更新

启动、回到前端和下拉刷新时，复古猫会在后台检查：

- 自动发现新增的 ROM 和索引变化。
- ROM 文件被删除后，如果网盘中也没有，就从列表隐藏。资料、收藏和存档关联会保留，文件恢复后沿用原记录。
- TF 卡拔出或暂时读取不到时，不会判定为删除，重新插入后自动恢复。
