复古猫的功能不止内置的这些。插件可以增加新功能和新页面，而且不需要修改主程序或重新打包 APK。

## 插件是什么

一个插件是一个 ZIP，包含清单 `plugin.json`、后台脚本和可选的网页。脚本通过公开的 SDK 调用复古猫的能力。

| 组成 | 作用 |
| --- | --- |
| 清单 | 声明名称、作者、版本、最低应用版本、需要的能力和页面 |
| 后台动作 | 在隔离的 JavaScript 引擎中运行，可以长时间处理、报告进度 |
| 页面 | 用 HTML、CSS 和 JavaScript 编写，在复古猫的导航内打开 |
| 配置 | 由宿主绘制表单，也可以自己写配置页。密钥字段会加密保存 |

## 插件能做什么

- 读取和修改游戏资料、收藏和最近记录
- 查询和关联已授权的媒体
- 保存扩展字段，并随索引同步到其他设备
- 访问声明过的网络主机
- 在你允许的网盘连接中读写 JSON 文档
- 为系统 ROM 同步增加额外的游戏资源
- 增加模拟器启动入口和搜索匹配方式

## 现在可以安装的插件

在 **插件 → 商店** 中可以安装：

| 插件 | 作用 |
| --- | --- |
| 收藏同步 | 通过已配置的网盘同步收藏，不传输 ROM、媒体或存档 |
| 最近游戏记录同步 | 同步最近游玩时间、次数和时长 |
| 拼音首字母搜索 | 用拼音首字母搜索游戏和应用，例如 `jsq` 搜索计算器 |
| Vita3K ROM 同步 | 同步 Vita3K 的游戏本体、补丁、DLC 和许可 |
| 自定义启动入口 | 选择平台并自定义模拟器启动参数 |

## 你如何控制权限

插件必须声明它需要的能力，你同意后才能启用：

| 能力 | 含义 |
| --- | --- |
| `LIBRARY_READ` | 读取游戏库 |
| `LIBRARY_WRITE` | 修改资料、收藏、最近记录和媒体关联 |
| `NETWORK` | 访问声明过的主机 |
| `STORAGE` | 读写你允许的网盘连接中的 JSON 文档 |

- 更新时如果新增了能力或主机，插件会保持停用，直到你重新同意。
- 可以访问任意主机的插件会被标为高风险。
- 插件读不到其他插件的扩展字段，也拿不到其他来源的配置和密钥。
- 可以随时在插件详情中停用或卸载，卸载时可以选择清除数据。

:::caution
插件可以运行代码，请只安装你信任的来源。
:::

## 不影响游戏

启动游戏不等待插件。后台脚本按需创建，任务结束后释放；关闭页面不会取消任务。中断后不会自动重放，可以手动重新运行。
