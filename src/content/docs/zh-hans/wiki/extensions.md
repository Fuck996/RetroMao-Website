---
title: 安装扩展
description: 添加扩展仓库，安装语言、平台、主题和插件。
---

扩展来自公开的 GitHub 仓库。官方仓库是 [RetroMao-Community](https://github.com/Fuck996/RetroMao-Community)，也可以添加其他人维护的 Fork。

## 添加仓库

1. 点击 **设置首页右下角** 没有文字的仓库按钮。
2. 每行填写一个公开 GitHub 仓库地址。
3. 保存。语言、主题、平台和插件共用这份列表。

要同时使用官方和社区内容，请保留各自的一行。清空列表后，不会请求任何仓库。

## 在线安装

| 类型 | 入口 |
| --- | --- |
| 语言 | 设置 → 主题与显示 → 语言 → 下载语言 |
| 主题 | 设置 → 主题与显示 → 社区主题 |
| 平台 | 设置 → 游戏库与文件夹 → 社区平台 |
| 插件 | 主导航 → 插件 → 商店 |

下载时会核对精确大小和 SHA-256，不一致的文件不会进入安装流程。在线下载需要能访问 GitHub。

## 离线安装

从仓库的 Release 下载 ZIP，**不要解压**，复制到设备后导入：

- 主题：**设置 → 主题与显示 → 导入主题包**
- 平台：**设置 → 游戏库与文件夹 → 导入平台扩展包**
- 插件：**插件 → 已安装** 中导入

## 安全

- 语言、平台和主题只包含配置与素材，不运行代码。
- 插件可以运行脚本，但只能使用它声明且你同意的能力。更新时如果新增了能力，插件会保持停用，直到你重新同意。
- 声明可访问任意主机的插件会被标为高风险，请只安装你信任的插件。

## 平台包不包含什么

平台包定义机种身份、扩展名和图标等，**不附带游戏和模拟器**。安装后仍需要添加 ROM 目录并配置模拟器。
