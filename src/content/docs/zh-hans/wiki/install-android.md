## 系统要求

- Android 8.0（API 26）及以上的手机、平板或安卓掌机
- 使用脚本插件时，需要较新的 Android System WebView
- 启动游戏需要另外安装对应的模拟器

## 安装

1. 打开 [下载页](../../download/)，下载 `RetroMao-x.x.x.apk`。
2. 可以用下载页提供的 SHA-256 核对文件。
3. 在设备上打开 APK。系统询问时，允许当前应用安装未知来源的应用。
4. 打开复古猫，按首次引导操作，然后进入游戏库。

## 升级

直接安装新版 APK 覆盖旧版即可，游戏库、设置和存档关联都会保留。

:::caution[共用网盘存档时]
使用同一份网盘存档的所有设备（包括 3DS）都应升级到最新版后再同步。旧版可能无法读取新版写入的索引。
:::
