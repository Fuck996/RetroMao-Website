---
title: 导入已有前端
description: 从 ES-DE、EmulationStation、Pegasus、LaunchBox 导入资料。
---

如果你已经用过其他前端，可以把资料导入复古猫。导入后会转换为复古猫自己的数据，日常使用和同步不再依赖原来的文件。

## 支持的格式

| 来源 | 索引文件 |
| --- | --- |
| ES-DE、EmulationStation | `gamelist.xml` |
| Pegasus | `metadata.txt`、以 `metadata.pegasus` 开头并以 `.txt` 结尾的文件 |
| LaunchBox | 平台 XML |

## 自动导入

添加 ROM 目录、重新扫描和下拉刷新时，复古猫都会检查目录里的兼容索引：

- 只有一份索引时，自动读取。
- 有多份索引时，先让你勾选，你的选择会保存。候选文件增减时再重新确认。
- ROM 和媒体的相对路径按索引文件所在目录解析，不需要重复映射。

## 手动导入

打开 **设置 → 游戏库与文件夹 → 导入已有游戏库**，选择索引文件。如果媒体路径超出授权范围（比如来自电脑的盘符路径），可以按提示重新定位。

## 机种如何识别

- Pegasus：读取已知的 shortname 和集合名
- LaunchBox：读取 Platform 字段
- 明确属于某个机种的 ROM 扩展名和目录名

无法判断时会让你选择，不会用当前浏览的机种代替。混合了多个机种的索引按机种分别导入。

:::note[外部启动命令不会执行]
索引里的启动命令不会被运行。游戏始终由你配置的模拟器启动。
:::

## 你的修改会保留

重新导入时，收藏、游玩记录和你修改过的资料都会保留。
