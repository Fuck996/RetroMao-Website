---
title: 安装 3DS 同步程序
description: 在 3DS 上安装同步程序，并通过局域网导入网盘配置。
---

3DS 同步程序通过系统存档服务直接读写游戏实际使用的存档，不依赖 Checkpoint。它支持 WebDAV 和百度网盘，并与 Android 版共用同一份网盘存档。

## 准备

- 已安装 Luma3DS 等自制固件，并可以运行 FBI。未改机的原厂系统不能安装 CIA，可以参考 [3DS Hacks Guide](https://3ds.hacks.guide/finalizing-setup.html)。
- 一台已经配置好网盘的 Android 版复古猫，并与 3DS 处于同一局域网。

## 安装

1. 从 [下载页](../../download/) 下载 `RetroMao-3DS-x.x.x.cia`。
2. 把 CIA 复制到 SD 卡的 `cias` 文件夹。
3. 打开 FBI，进入 `SD → cias`，选中 CIA，选择 `Install and delete CIA`，按 A 确认。
4. 返回 HOME 菜单，打开 RetroMao。

升级时用 FBI 安装新版覆盖即可。`sdmc:/3ds/RetroMao/` 中的配置、任务记录和备份会保留。

## 导入网盘配置

3DS 上不能手动填写账号，配置只通过局域网一键配置导入。

1. 在 3DS 上打开 `START → 同步设置 → 一键配置 → 我是新设备`，屏幕会显示本机 IP 和四位配对码。
2. 在 Android 版打开 **设置 → 网盘与 WebDAV → 一键配置 → 我是老设备**，发现或手动输入 3DS 的 IP，再输入配对码。
3. 勾选要传输的连接，点击“同步配置”。
4. 回到 3DS 的同步设置，选用一个同步来源。

## 同步存档

1. 在下屏网格中选择游戏：触摸或按 A 勾选，方向键移动焦点，L/R 翻页。
2. 按 START，选择 **同步存档**，确认所选的游戏和来源。
3. 等待完成。上屏会显示实际阶段和逐项结果。

:::note[中断了也不用担心]
下载的存档会先完整暂存并校验，再备份当前存档，最后写入。中断后需要先恢复或完成原任务，才能继续同步。
:::

下屏左上角的 `Language`（SELECT）可以切换简中、繁中、英语和日语。

## 限制

- 部分游戏的扩展存档需要确认归属后才能同步，程序会列出游戏和档案 ID，由你确认或跳过。
- 部分系统（如 Luma3DS 7.1）限制 Loader 连接，可能无法确认扩展存档，结果中会注明。
- 存档存在不可读区域时，结果会显示“已同步可读区域”和原始错误码。这个过程不会修复损坏的数据。
- 凭据绑定当前主机，复制 `sdmc:/3ds/RetroMao/` 到另一台主机不能代替一键配置。
