---
title: 安装与升级主题
description: 安装社区主题或本地主题包，预览、切换和升级已安装的主题。
---

## 安装主题

- **从社区下载**。打开 **设置 → 主题与显示 → 社区主题**，核对主题的作者、版本和仓库，勾选要安装的主题，点击 **下载并安装**。
- **导入 ZIP**。将作者提供的主题 ZIP 原样复制到设备，打开 **设置 → 主题与显示 → 导入主题包**，选择 ZIP 文件。导入可离线完成。

## 选择或预览主题

安装完成后，打开 **设置 → 主题与显示 → 主题**。已安装的主题排在内置主题前面。点选主题名称即可切换，也可以点击该行的眼睛图标进入 **预览主题**，再用顶部的 **应用主题** 保存，或点 **退出预览** 回到原来的外观。

## 升级已安装的主题

- **社区主题**。打开 **设置 → 主题与显示 → 主题**。有来自原仓库且与当前复古猫版本兼容的更新时，主题右侧会显示 **更新到某版本** 的下载图标。点击图标，等待下载和安装完成，再核对主题旁的版本号。若显示 **安装社区版**，这是将未记录社区版本的本地主题换成对应的官方社区版。
- **本地主题包**。通过 **导入主题包** 选择作者提供的同一主题的新版 ZIP。包内主题 ID 相同时，新包校验通过后会替换已安装的旧包。

直接升级即可保留当前的主题选择。若未显示社区更新，检查网络和原仓库是否仍在仓库列表中。若社区目录提示需要更高版本的复古猫，请先升级应用。下载或校验失败时，已安装的主题包会保留。
