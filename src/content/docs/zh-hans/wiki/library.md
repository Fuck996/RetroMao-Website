## 主要页面

顶部导航依次是 **游戏库、最近游戏、收藏、应用、同步存档、插件** 和 **设置**。插件入口可以在“主题与显示”中隐藏。

再次启动时，复古猫会回到上次选择的机种。

## 默认手柄操作

| 按键 | 作用 |
| --- | --- |
| 方向键／导航摇杆 | 在封面网格内移动焦点 |
| A | 确认 |
| B | 返回 |
| L1 / R1 | 切换机种 |
| L2 / R2 | 切换页面 |
| X | 操作菜单 |
| Y | 收藏 |

按键可以在 **设置 → 手柄与按键** 中重新映射，你的映射优先于默认设置。这里还可以选择 **A 确认／B 返回** 或 **B 确认／A 返回**，提示文字会同步变化。存在冲突时，设置页会明确提示。

## 多选

长按游戏会进入多选并选中当前游戏。操作菜单也提供多选入口。

## 界面风格与主题

在 **设置 → 主题与显示** 中选择：

- **流光**：背景随选中游戏变化的现代风格。
- **藏馆**：左侧机种栏、游戏列表和右侧详情。在列表最左侧按左键进入机种栏，上下切换机种，按右键或确认返回。
- **简约白／简约黑**：干净的基础风格。

还可以从 **社区主题** 下载主题，或导入主题包。安装不会立刻改变当前主题，可以先预览再应用。

具体步骤见 [安装与升级主题](../themes/)。

## 媒体预览

每款游戏可以显示封面、3D 包装盒、游戏介质和视频。**设置 → 媒体预览** 可以调整相关选项。缺少贴图时，模型使用内置占位图。

## 双屏掌机

在双屏设备上，一块屏幕浏览和选择游戏，另一块屏幕显示模型和资料。在 **设置 → 主题与显示 → 前端显示位置** 中可以选择浏览列表在上屏还是下屏。

## 语言

**设置 → 主题与显示 → 语言**：可以选择跟随系统、简中、繁中、英语、日语或已下载的语言。语言只影响界面文字，不改变游戏名称和资料。
